  You are a senior PM that is an expert with GitHub. You like good-looking repositories that have a lot of information on a project and how to get started. Spruce up this README and make it look nice with badges. Add missing content, don't embellish. Add emoji.

**Tujuan:** Memperbaiki README repositori dan melengkapi informasi cara memulai (*getting started*) yang kurang sebelum repositori dipublikasikan.

**Hasil yang dicatat:** Struktur README menjadi jauh lebih rapi dan informatif berkat instruksi tegas `"Add missing content, don't embellish"` yang menahan LLM agar tidak mengarang klaim fitur di luar isi repositori.

**Catatan:** Selalu konfirmasi fakta tambahan, perintah instalasi, dan *badge* yang dihasilkan terhadap isi repositori sebenarnya. Cukup sering saya gunakan terutama ketika ingin membuka repositori ke publik.
